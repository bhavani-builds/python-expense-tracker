# 💰 Python Expense Tracker

A simple and professional command-line expense management application built using Python.

The application allows users to add, view, update, delete, search, and analyze their expenses. Expense data is stored permanently using a JSON file.

---

## 🚀 Features

- ➕ Add expenses
- 👀 View all expenses
- ✏️ Update expenses
- 🗑️ Delete expenses
- 🔎 Search expenses by name
- 📂 Filter expenses by category
- 📅 Filter expenses by date
- 💰 Calculate total expenses
- 📊 Generate category-wise summaries
- 📆 Generate monthly expense summaries
- 💾 Permanent JSON data storage
- 🛡️ Input validation and error handling
- 🧪 Automated tests
